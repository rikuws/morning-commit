AGENT MEMORY

Anthropic lets Claude 'dream': offline passes that fix and reorganise an agent's notes

In a new engineering post, Anthropic explains how Claude agents keep memory as readable notes between sessions, then replay old transcripts while idle to correct wrong notes, merge duplicates and build wikis. In Pokémon Red, a dream fixed a bad note that had trapped Claude in a loop. Dreams are now a research preview in Claude Managed Agents, and the input memory store is never modified.

Source: Anthropic · anthropic.com

SECURITY

DeepMind's agents find two new weak spots in legacy 1024-bit RSA

Working under human supervision, the agents showed that once an attacker controls about half of a signed block, padding adds no real protection, and found a theoretical forgery attack about 1,600× faster than the previous best. A batch method cuts the cost of each extra 1024-bit key by about 30×. Modern 2048-bit keys are not affected.

— Interesting Engineering · interestingengineering.com
OPENAI

OpenAI invites Hacktron to attack its own systems

The AI security firm, found through OpenAI's bug bounty, will pick high-priority targets with OpenAI's engineers, focusing on where OpenAI's services connect to third-party ones. Hacktron also gets wider access to frontier models through Daybreak Red. It follows a security sprint with Cathedral and higher bounty rewards earlier in the week.

— OpenAI · openai.com
AGENTS

Google ADK 2.14 makes A2A and sandboxed environments stable

Google's open-source Agent Development Kit moves the agent-to-agent protocol, execution environments (including E2B and Daytona sandboxes), evaluation and the core runtime out of experimental. It also adds multi-run evals with semantic tool-argument matching, a Microsoft Teams runner and faster long multi-turn workflows.

— GitHub · google/adk-python · github.com
FINLAND

Lappeenranta's Finnos runs sawmills with AI agents

Finnos showed a system where agents with APIs to every scanner and program see log stock, saw line, kilns and orders at once. They re-plan production whenever something changes, a person picks the plan, and agents carry it out down to the machines. It already runs at two Finnish sawmills, with a Swedish rollout starting.

— Finnos / ePressi · epressi.com
