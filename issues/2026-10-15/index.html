Lead story · OpenCode

OpenCode 2.0: one local service, Code Mode, and background agents

Anomaly’s open coding agent just shipped a major rewrite: TUI, web and desktop now share one auto-started local backend, MCP tools become scriptable functions in Code Mode (one round-trip instead of tool-call ping-pong), and background subagents plus async shell keep the main agent unblocked. Plugins are stable (80+ shipped as internal ones first), the server API is rebuilt, and V1 plugins don’t run — upgrade with `opencode upgrade --major`. Changelog already at v2.0.29 as of 14 Oct.

Source: Anomaly · anoma.ly

The Wire

Models

A five-person lab ships Ultramarine 1 Flash for non-verifiable knowledge work

Paper Instruments post-trained GLM-5.3 Flash with RL on finance, law, consulting and ops tasks where there’s no unit test — and says it beats its base by 4.1 points on six knowledge-work benches while using 6.5% fewer tokens. API is live; weights ‘coming soon’. Their numbers, on their Feather harness.

— Paper Instruments · paperinstruments.com
Safety

Kiro’s local command sandbox is generally available

Agent shell commands now run under OS-enforced limits (Seatbelt / bubblewrap / AppContainer): project writes only, credential paths denied at the kernel, network through a domain filter. Off by default — `/sandbox on` or a sandbox.json. The agent stays outside so you can flip it mid-session; Kiro says it’s not total isolation.

— Kiro · kiro.dev
Dev tools

Antigravity CLI gets Auto mode — safe commands without the prompt tax

Google’s Antigravity 1.3.5 (14 Oct) auto-approves file edits and ‘safe’ shell commands, still asks before irreversible work, and routes sandbox escapes to a separate review agent. `--mode auto`, Shift+Tab, or /config — Linux and macOS now, Windows later. Same cut: on-demand /compact and a faster /diff.

— GitHub · github.com
Open source

Graphicle: a Rust code graph + memory for Claude Code, Cursor and Codex

KarLex AI’s Apache-2.0 local MCP tool indexes repos with tree-sitter, keeps session memory in SQLite, and feeds agents cited excerpts under a token budget — no account or API key for the graph itself. They clocked Kubernetes (31k files) in 3m 18s vs Graphify’s 26m 38s on the same box; Show HN yesterday.

— GitHub · github.com
