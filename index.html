Lead story · Open source

DeepSeek open-sources DeepInfer, the engine that serves its own API

A day after the US ordered federal agencies to rip out its products, DeepSeek published the inference framework it runs in production, under Apache 2.0. For now it supports only DeepSeek-V4.1-Flash, on Nvidia SM100 GPUs and Huawei Ascend 950 chips, with speculative decoding, asynchronous scheduling, batch-invariant and deterministic sampling, and structured outputs. It isn’t a full service yet: the KV cache system, prefill/decode split and replica load balancing are left out. A companion library, deepseek-recipe, reproduces how the official API turns requests into tokens and back. The speed numbers are DeepSeek’s own; the repo passed 8,000 stars by Tuesday afternoon.

Source: The Next Web, The New Stack, DeepSeek on GitHub · thenextweb.com

The Wire

Safety

Anthropic’s automated red-teamer beat its human bug bounty 23 times out of 24

Tested on the same 8 bounty questions and 3 generations of its bioweapons classifiers, the system matched or beat the best human submission in every pair and won 23. It took 24 to 48 hours instead of the bounty’s weeks to months, so Anthropic ticked off a goal it had set for January 2027. A longer write-up is promised.

— Anthropic · anthropic.com
Dev tools

OpenAI spells out how to keep its models in Cursor after the 12 November cutoff

A new help page lists three routes: your own OpenAI API key, the Codex IDE extension inside Cursor, or an OpenAI-compatible gateway such as Bedrock or Azure. The catch: a bring-your-own key only works in local Chat and Agent, not in Tab, Auto, cloud agents, automations, the CLI or the SDK.

— OpenAI Help Center · help.openai.com
Infra

TorchTPU goes open source: plain PyTorch now runs natively on Google TPUs

Co-developed with Meta’s PyTorch team and announced at PyTorch Conference, it supports eager mode, torch.compile and distributed primitives, and Transformers v5 deploys with device_map="tpu". Alongside it: vLLM and SGLang backends, llm-d 1.0 for Kubernetes inference routing, and a TPU agent suite in preview for coding harnesses.

— Google Cloud Blog · cloud.google.com
Nordics

Aalto spin-out Coherence Quantum raises €2.78M to fix how quantum computers scale

The Espoo startup builds cryogenic signal and control hardware that sits close to the qubits, so bigger processors don’t need ever more cabling and cooling. Lifeline Ventures led the seed, with Mårten Mickos as an angel. The team includes a key builder of Aalto’s 20-qubit Q20 machine and an ex-Bluefors product lead.

— Uusiteknologia.fi · uusiteknologia.fi
