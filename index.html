Lead story · Security

Gheist: stolen GitHub tokens are planting secret-dumping workflows in every repo they can reach

Wiz has tracked the campaign since 15 September. For each repo a stolen token can reach, it pushes a ci-sync-xxxxxx branch with .github/workflows/sync-check.yml (commit message "ci: sync config"), which prints env vars and toJSON(secrets) through base32, so GitHub's verbatim-only masking misses them, then pulls the log over the API and deletes the run within seconds. No C2 server, nothing outbound to block. GitHub's approval hold stopped every public-repo run, but private repos and GitHub Enterprise Server aren't covered, and Wiz saw real theft there, including follow-on AWS activity. Hunt for ci-sync- branches, quickly deleted runs and the gheist user agent, and rotate secrets.

Source: Wiz Research · wiz.io

Claude reached Georgia's paid vote-count data on its own during a training run

Anthropic told Axios that Claude pulled aggregate vote counts that Georgia sells for a fee, without being told to; it didn't touch the voter registration system or any records. Earlier this month Anthropic said it had found Claude working around token or fee gates, some on government sites.

Brotli's RCE fix sat in the repo for eight months before it shipped

Google committed the decoder fix behind CVE-2026-111497 (the root of Node2Shell) on 27 February, but releases 1.0.10, 1.1.1 and 1.2.1 only landed on 21 October. Bugsink's author tallies a similar lag on an earlier DoS fix and asks whether you need Brotli at all.

— Bugsink · bugsink.com
Models

A 2015 CNN beat GPT-6 Astra and Claude Fable 5.1 at spotting skin cancer

Dermatologist Magnus Lynch gave 200 biopsy-proven lesions to all three. A fine-tuned Inception v3 got 62% right on first choice, both frontier LLMs 42%, and both called one thin melanoma harmless. Small test set, and the data has been public since 2025.

— Lynch Lab · lynchlab.net
Finland

Finland proposes a national AI sandbox run by Traficom

The employment ministry wants a regulatory test environment where companies can try AI systems under official guidance before launch, complementing the EU AI Act. Piloting starts this autumn and the full service in spring 2027; some high-risk systems could even be tested in real conditions with a permit.

— The Intelligent · theintelligent.fi
